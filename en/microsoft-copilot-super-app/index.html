Microsoft relaunches Copilot as a chat, code and agents super app

Three tabs — Home, Code and Autopilot — and the Scout assistant is renamed Autopilot.

2026-09-28 · EmaritesAI

Microsoft has officially launched the Copilot "super app" it teased last month, and it is pitching it as broadly as it once pitched Office, The Verge reports.

The redesigned app bundles three capabilities into one interface, organised as three tabs. Home combines Copilot Chat and Cowork and is the default landing page; Microsoft plans to add a Today view there that works as a personal dashboard for important emails, meeting requests and Teams threads. Autopilot is the new name for Scout, the AI personal assistant Microsoft unveiled at Build earlier this year.

The surprise is the Code tab. Aimed at knowledge workers rather than developers, it lets anyone create an app, tracker, dashboard or automation and share it with colleagues as a cloud-hosted internal app.

"Home is where you get your bearings," said Jared Spataro, Microsoft's chief marketing officer for AI at work, describing it as the place to review recent activity and pick up work where you left off.

The move puts Microsoft in direct competition with standalone assistants from OpenAI, Anthropic and Google, and with the wave of consumer agent apps such as Meta's Muse, by folding chat, building and delegation into the software millions of office workers already open every day.

3 things to know
  1. New Copilot app has three tabs: Home, Code and Autopilot
  2. Scout assistant is renamed Autopilot
  3. Code tab lets non-developers build and share internal apps
Sources: The Verge
