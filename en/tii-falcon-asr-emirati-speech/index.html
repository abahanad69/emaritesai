TII releases Falcon-ASR, a 1.6B speech model tuned for Emirati

Abu Dhabi's Technology Innovation Institute says its new model beats the best published Arabic leaderboard average by 2.25 points.

2026-10-08 · EmaritesAI

The Technology Innovation Institute (TII) in Abu Dhabi released Falcon-ASR on 7 October, a speech recognition model with 1.6 billion parameters. It is built mainly for Arabic, with particular attention to the Emirati dialect, and the same weights also handle English, French, Spanish and Portuguese without a language setting.

TII measured it on the Open Universal Arabic ASR Leaderboard, run by the ELM Research Center, which averages six Arabic test sets. Falcon-ASR scored a word error rate (WER) of 20.92%, meaning roughly one word in five is wrong, against 23.17% for the best published result in the snapshot TII checked on 30 September. Lower is better.

On TII's own Emirati test set, built from held-out recordings with human-checked transcripts, the model reached 22.73% WER and 10.19% character error rate, 4.07 points better than Qwen3-Omni, the next system in TII's comparison. In English it averaged 5.74% WER across the seven test sets used by Hugging Face's Open ASR Leaderboard.

TII says it trained on Emirati speech, Modern Standard Arabic, other Gulf and Arabic dialects and English, and added noise, overlapping voices, music, echo and phone-line effects so the model copes with real meetings and calls. It also returns word-level timestamps.

For now, the public route is a demo on Hugging Face. TII says API access and native apps are coming; the announcement does not link downloadable weights or name a licence.
