What does '78B with 3.46B active' mean? Mixture of experts explained

Many new models store a lot of knowledge but use only a small slice of it for each word.

2026-10-04 · EmaritesAI

When a model card says '78B total, 3.46B active', it is describing a mixture-of-experts (MoE) design. Aleph Alpha's Kolibri, released this week, is one example.

In a standard dense model, every parameter does work for every word. An MoE model replaces some layers with a group of smaller networks called experts, plus a router. For each token, the router picks a few experts and skips the rest. Kolibri has 384 experts in each layer and picks 6 per token.

The benefit is speed and cost. Because only a small slice of the network runs for each token, an MoE model can answer faster than a dense model of the same total size, and it is cheaper to train to a given quality, according to Hugging Face's guide to the technique.

The catch is memory. All the experts still have to be loaded, even though only a few are used at a time. Mixtral 8x7B, an early popular MoE model, needs about 47B parameters in memory but computes roughly like a 12B model.

So the total number tells you how much hardware you need to hold the model. The active number gives a better idea of its speed.

Explained simply
  1. Experts: Some layers are split into many smaller networks, each called an expert.
  2. Router: A small gate network picks which few experts handle each token.
  3. Active count: Only the chosen experts compute, so the model runs faster.
  4. Total count: Every expert must still sit in memory, so hardware needs stay high.
  5. Reading specs: '78B-A3B' style names give total size first, then active size.
3 things to know
  1. An MoE model uses a router to send each token to a few expert networks.
  2. Active parameters drive speed; total parameters drive memory needs.
  3. Kolibri picks 6 of 384 experts per layer, using 3.46B of 78B parameters.
Sources: Hugging Face: Mixture of Experts Explained, Hugging Face: Aleph-Alpha/Kolibri-1 model card
✅ Kolibri: 78B total, 3.46B active, 384 experts per layer, 6 per token
⚠️ MoE uses sparse expert layers and a router; faster inference and cheaper pretraining than dense models of equal size
⚠️ All experts must be loaded in memory
⚠️ Mixtral 8x7B needs ~47B params in memory, computes like ~12B
