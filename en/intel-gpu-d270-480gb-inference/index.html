Intel's GPU D270 puts up to 480GB of memory on one 350W card

The inference card swaps expensive HBM for LPDDR5X so it fits ordinary air-cooled servers, and Intel says one card can hold a 300B-parameter model.

2026-10-13 · EmaritesAI

Intel used the Open Compute Project Global Summit in San Jose on October 12 to give its Crescent Island accelerator a product name: the GPU D-series. The first part shown is the GPU D270, a card built only for running AI models, not for graphics.

The main selling point is memory. Intel's product page lists up to 480GB of LPDDR5X per card, a type of memory used in laptops and phones, instead of the high-bandwidth memory found on Nvidia's and AMD's data center chips. StorageReview reports that Intel's own branded card carries 160GB and that the 480GB figure applies to partner-built versions, with bandwidth of 1.5TB/s and 1.3 petaflops of FP8 compute. The card has 32 Xe3P cores and 256 matrix engines.

The D270 is a 350W, air-cooled PCIe 5.0 card, so it can go into existing server racks without liquid cooling. Intel says a single card can host models of about 300 billion parameters and that an eight-card server can pass one trillion. The company is aiming it at agent workloads with long contexts and many users at once, where memory capacity matters more than peak speed.

Intel says customer sampling is under way with server makers, cloud providers and software vendors. It has not given a price or a date for volume shipments. Dell, HPE, Lenovo and Supermicro were among 53 partner logos on Intel's keynote slide.
