Google unveils Gemini agent to run work tasks across apps

The cloud-based agent can spin up sub-agents, give coworker agents their own email address, and choose between Gemini and Claude models.

2026-10-08 · EmaritesAI

Google Cloud chief executive Thomas Kurian announced the Gemini agent on Thursday at Gemini at Work 2026. Google calls it a universal agent for work: from one prompt box or one API it answers questions, drafts documents, creates images and media, and writes and runs code.

The agent runs in Google's cloud, so a long task keeps going after the user closes the laptop. Google says it can create short-lived sub-agents for parts of a job that run for hours or days, and persistent "coworker agents" with their own identity, storage and an @agents.company.com email address. It picks the model for each task, and Kurian said that today includes Google's Gemini models and Anthropic's Claude.

People can reach it on the web, iOS, Android, Windows, Mac and the command line, inside Gmail, Docs, Sheets and other Workspace apps, and from Microsoft 365 and Slack. Connectors cover tools such as Jira, Salesforce, ServiceNow, Snowflake and any MCP server.

Each agent gets its own identity with limited permissions and runs in a sandbox, and companies can set spending caps that pause an agent when reached. Google also announced versions for financial services and legal work, both in preview.

According to The Verge, the Gemini agent is available only to enterprise customers in private preview inside the Gemini Enterprise app. Google did not give a general release date or pricing.

3 things to know
  1. Gemini agent handles questions, docs, media and code from one prompt
  2. Coworker agents get their own @agents.company.com email address
  3. It can use Gemini or Anthropic's Claude; private preview for now
