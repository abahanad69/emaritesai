UpGuard finds 16,000 Supabase databases exposing personal data

Researchers tie the leaks to misconfigured, often vibe-coded apps; Supabase says projects are secure by default.

2026-09-28 · EmaritesAI

Thousands of databases hosted on developer platform Supabase are exposing people's personal information to the public web, according to new research by security firm UpGuard reported by TechCrunch.

UpGuard says it found around 16,000 databases on which some degree of personal data was exposed. The data included names, addresses, phone numbers and user passwords, with a smaller number of authentication tokens. Exposed projects ranged from a US valet service's licence-plate records to an immigration and relocation service and a virtual SIM farm used to receive one-time passcodes. Most datasets appear to be in the US, but UpGuard calls it a worldwide problem.

Supabase reached a $10 billion valuation this year, helped by developers hosting "vibe-coded" apps built with AI tools. The findings show how such apps can leak data through basic misconfigurations, since generated code may contain security flaws or need setup the developer is not aware of.

Supabase chief information security officer Bil Harmer said the company had not seen the research, but that its projects are secure by default and security is shared between the platform and its customers, who control how their projects are configured. He said Supabase notifies affected customers when it finds issues.

3 things to know
  1. ~16,000 Supabase-hosted databases exposed personal data
  2. Names, addresses, phone numbers and some passwords leaked
  3. Supabase: secure by default, security is shared
