What is a context window, and does 1M tokens mean better answers?

Meta's Muse Wonder launched with a 1M-token window. Here is what that number covers and where it stops helping.

2026-10-13 · EmaritesAI

When Meta released Muse Wonder this week, one of the headline figures was its 1 million token context window. The context window is the model's working memory: everything it can look at while writing a reply. It is separate from what the model learned in training.

The window holds more than your question. According to Anthropic's documentation, it includes the system instructions, every message in the chat, attached documents, images and tool results, plus the reply the model generates. A long chat or a big PDF uses up space even if your latest message is short. If the input alone is larger than the window, the request fails.

A bigger window lets you hand over a full contract, a codebase or months of notes in one go. It does not guarantee the model uses all of it well. Anthropic says accuracy and recall drop as the token count grows, an effect it calls context rot. So what you put in matters as much as how much fits.

For everyday use, start a new chat when you switch topics, attach only the files that matter, and ask the model to quote the part of a document it relied on so you can check it.

Explained simply
  1. Know what counts: Instructions, every message, attachments and the reply all use the window.
  2. Size is in tokens: Windows are measured in tokens, small chunks of text, not words or pages.
  3. Bigger is not sharper: Recall can drop as the window fills, an effect Anthropic calls context rot.
  4. Start fresh often: Open a new chat when you change topic so old text does not crowd the window.
  5. Ask for quotes: Have the model cite the passage it used so you can check it in the source.
3 things to know
  1. The context window is everything a model can see while it replies
  2. It counts your files, the whole chat and the model's own answer
  3. Recall can drop as the window fills, so keep inputs focused
Sources: Anthropic docs: Context windows, Meta for Developers: Build with Muse Wonder
✅ Muse Wonder has a 1M-token context window
⚠️ Context window includes system prompt, messages, attachments, tool results and output
