Deno team joins Cloudflare; Deno Deploy to shut in six months

Creator Ryan Dahl says the team will focus on Workers and Durable Objects, with AI agents a main target.

2026-10-10 · EmaritesAI

The entire Deno team is joining Cloudflare, Deno creator Ryan Dahl announced on October 9, in a move that ends development of a well-known alternative to Node.js.

Dahl said the team will put its future work into a shared platform built on Cloudflare's Workers programming model rather than keep developing a separate runtime and hosting service. He is working on a system called celld, which builds on Workers and Durable Objects so that applications scale without each team assembling its own infrastructure. The aim, in Cloudflare's words, is to make self-hosting Workers and Durable Objects much simpler.

For current users, Deno says the runtime will receive monthly releases with bug fixes and security updates for one more year, after which its own development ends. The code stays open source and others are welcome to continue it. Deno Deploy will run for six more months before shutting down, with migration help to Cloudflare Workers for paying customers. The JSR package registry will keep running on Cloudflare infrastructure.

AI is a large part of the reasoning. Dahl wrote that Durable Objects offer cheap serverless execution, persistent state and WebSockets, which suit the harnesses that run AI agents, and that this is what he is most excited to explore. He asked developers building agents at scale on their own infrastructure to contact him.
