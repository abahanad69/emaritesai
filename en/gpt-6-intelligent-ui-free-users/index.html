GPT-6 with Intelligent UI reaches free ChatGPT users

Answers can now mix text with charts, buttons, forms and small tools that work inside the chat.

2026-10-08 · EmaritesAI

OpenAI is rolling out GPT-6 with a new answer format it calls Intelligent UI. Paid ChatGPT plans (Plus, Pro, Business and Enterprise) received it on Wednesday, and the Free and Go tiers follow on Thursday, according to OpenAI.

Intelligent UI lets a reply mix text with charts, tappable buttons, forms and small interactive tools that work inside the chat. OpenAI's examples include a road-trip map with stops, a retirement savings calculator, a dinner bill splitter and a bicycle broken down into five tabbed systems. Simple questions can still get plain text, and TechCrunch reports that users can ask for fewer visuals in their settings.

Free and Go accounts run a model called GPT-6 Luna, while paid plans use GPT-6 Sol. OpenAI says GPT-6 Instant starts answering questions that need a web search 44% sooner on average than GPT-5.6 Instant, a figure the company measured itself. The models behind Work and Codex do not change.

OpenAI says more than 1.2 billion people use ChatGPT each week, so the new format reaches a very large audience in two days. The company says the interface is drawn by a component library that renders it while the model is still writing. A system card with the safety testing was published with the release.

  2. Replies can include charts, buttons, forms and in-chat tools
  3. OpenAI says web-search answers start 44% sooner than GPT-5.6
