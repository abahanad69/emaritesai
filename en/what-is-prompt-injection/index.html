What is prompt injection, and why do AI agents make it worse?

Hidden instructions in a web page or file can steer an AI assistant, and the risk grows once the assistant can act for you.

2026-10-09 · EmaritesAI

Prompt injection happens when text that an AI model reads changes its behaviour in ways its user or developer did not intend. The security group OWASP lists it first in its 2025 Top 10 risks for applications built on large language models.

There are two kinds. In direct injection, the person typing tries to talk the model out of its rules. In indirect injection, the instructions hide inside content the model processes, such as a web page, an email or a PDF. OWASP notes that people do not even need to see the text for it to work, as long as the model reads it.

The risk grows with AI agents. A chatbot that only writes text can be fooled into a bad answer. An agent that can send emails, browse, edit files or run code can be fooled into doing something.

There is no complete fix, so defences come in layers. OWASP recommends giving the model only the permissions it needs, labelling untrusted content clearly, checking outputs with ordinary code and asking a human before risky actions. Some companies add monitors on top. This week, Goodfire launched probes that watch a model's internal activity and said they caught 94% of malicious hacking sessions in its tests.

Explained simply
  1. The basic trick: Text the AI reads tries to override what the user or developer told it.
  2. Direct: The person typing tries to talk the model out of its rules.
  3. Indirect: Instructions hide in a web page, email or file the model processes.
  4. Agents raise stakes: An AI that can send, browse or run code can be tricked into acting.
  5. Layered defence: Least privilege, labelled inputs, output checks and human approval.
3 things to know
  1. Prompt injection is text that hijacks what an AI was told to do
  2. OWASP ranks it the top risk for LLM applications (2025)
  3. Agents that can act raise the stakes; defences come in layers
