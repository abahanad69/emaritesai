H Company releases Holo4 models for computer-use agents

A 27B dense model and a 35B-A3B mixture-of-experts work across screens, code, MCP tools and APIs.

2026-09-28 · EmaritesAI

H Company has released Holo4, a new series of models for AI agents that operate software, the startup announced on the Hugging Face blog. It comes in two sizes, a 27-billion-parameter dense model and a 35B-A3B mixture-of-experts model, and is available through the H Models API, with FP16, FP8 and GGUF versions published on Hugging Face. An updated small model, Holotron4 Nano, ships alongside.

The pitch is one model for every interface. Holo4 can click and type on a screen, write and run its own code, and call MCP or API tools, choosing whichever fits the task. The company says it runs on desktops, the web, Android, code sandboxes and business APIs without switching models.

Holo4 is built on Qwen base models and was trained with supervised and reinforcement learning on a large set of environments, including tasks generated by what H calls its Agentic Task Factory.

On the OSWorld 2.0 desktop-control benchmark, the company reports 61.7% for Holo4 27B and 30.9% for the 35B-A3B model, against 81.8% for Anthropic's Claude Opus 5.5. H argues Holo4 competes with frontier models at a much lower cost per task, and it has published every benchmark trajectory for others to replay.

3 things to know
  1. Two sizes: 27B dense and 35B-A3B mixture-of-experts
  2. One model for screens, code, MCP tools and APIs
  3. 61.7% on OSWorld 2.0 vs 81.8% for Claude Opus 5.5
Sources: Hugging Face (H Company)
⚠️ Holo4 27B and 35B-A3B released; weights and API available
