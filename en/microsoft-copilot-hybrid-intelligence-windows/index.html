Microsoft lets Copilot read and act on files on your Windows PC

Windows Hybrid Intelligence splits work between local and cloud models and asks permission before Copilot touches your files.

2026-10-08 · EmaritesAI

Microsoft used its Windows and Surface event in San Francisco on 7 October to announce Windows Hybrid Intelligence, a set of features that gives Copilot access to the files on a PC and the ability to act on them.

Jacob Andreou, Microsoft's executive vice president of Copilot, listed three changes: Copilot can draw on all the files on the computer, it can take actions such as moving files and changing settings, and it can hand tasks to models running on the device when cost or privacy matter more. Harder jobs still go to the cloud. Microsoft says access to local files and recent activity needs the user's permission.

In an onstage demo, Copilot's Autopilot agent read an email from Andreou's accountant, collected tax documents from different folders, renamed and sorted them, zipped them and drafted a reply with the file attached. It stopped for his approval before sending, and the sorting ran on models on the laptop, so the tax data did not go to the cloud.

Chief executive Satya Nadella described Windows as becoming a hybrid system that mixes cloud and local AI. The features are due on Copilot+ PCs in the coming months. A Windows 11 search box with thousands of quick actions, such as switching on dark mode or sending a text, began rolling out to Windows Insiders on 7 October, and an experimental release later this month lets GitHub Copilot send simple coding tasks to a model on the PC.

3 things to know
  1. Copilot will search PC files and act on them, with user permission
  2. Simple tasks can run on local models when cost or privacy matter
  3. Features reach Copilot+ PCs in the coming months, Microsoft says
Sources: GeekWire, The Verge, Fortune
