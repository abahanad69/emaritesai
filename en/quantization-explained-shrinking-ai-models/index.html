How do big AI models fit on a gaming PC? Quantization

Storing each number in fewer bits cuts memory by up to three quarters, at a small cost in accuracy.

2026-10-05 · EmaritesAI

An AI model is mostly a huge list of numbers called weights. They are usually stored at 16 bits each, so every billion weights takes about 2GB of memory.

Quantization stores those numbers with fewer bits: 8, 4 or even 2 or 3. Going from 16 bits to 4 cuts the memory needed by about three quarters. Google's new DiarizationLM model shows the effect: the full 16-bit version is about 16GB, while its 4-bit file is about 5.3GB.

The trade-off is precision. Rounding numbers loses detail, and the model's answers can get slightly worse. At 8 and 4 bits the loss is usually small. At 2 or 3 bits it becomes more noticeable, which is why some methods calibrate on sample data first.

You see quantization in file names. Tools like llama.cpp and Ollama use the GGUF format, with labels such as Q4_K_M or IQ3_S that describe the bit width and method. Strata, a new open source project, uses 2- to 4-bit versions to run a very large Qwen model on a 12GB graphics card.

Before downloading a local model, compare the file size with your graphics card memory and RAM, and start with a 4-bit version.

Explained simply
  1. Count the bits: At 16 bits, each billion weights needs about 2GB of memory.
  2. Read the file name: Labels like Q4_K_M or IQ3_S tell you the bit width and method.
  3. Start at 4 bits: It usually keeps quality close to the original at a quarter of the size.
  4. Go lower only if needed: 2- and 3-bit files fit smaller machines but lose more accuracy.
  5. Check your hardware: Compare file size with your GPU memory and RAM before downloading.
3 things to know
  1. Quantization stores model weights in fewer bits to save memory
  2. 16-bit to 4-bit cuts the memory needed by about three quarters
  3. Below 4 bits, answer quality drops more noticeably
Sources: Hugging Face Transformers docs: Quantization overview, Google DiarizationLM-Gemma-4-E4B model card, Strata (GitHub)
