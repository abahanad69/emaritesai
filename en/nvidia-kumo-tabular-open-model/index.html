NVIDIA releases Kumo Tabular, an open model for spreadsheet data

It predicts labels for new rows in one pass, with no training or feature engineering, and tops four benchmarks.

2026-09-30 · EmaritesAI

NVIDIA has released Kumo Tabular, an open foundation model for tabular data, the kind of rows and columns behind customer records, transactions and sensor logs, the company announced on the Hugging Face blog.

For two decades, predicting things like churn, default or demand from tables has meant training a separate model for each task, usually gradient-boosted trees, with feature engineering and tuning each time. Kumo Tabular instead works like in-context learning in chatbots: you give it a table with labelled rows and the rows you want predicted, and it returns class probabilities or numeric predictions in a single forward pass, with no training.

The model is a Transformer built around table structure, using column, row and in-context attention. NVIDIA says it was pretrained only on artificially generated data.

It comes in three sizes, from 28 million to 215 million parameters, small enough to run on modest hardware. Weights are on Hugging Face and code on GitHub, under the OpenMDW-1.1 licence, which allows commercial use.

NVIDIA says Kumo Tabular ranks first on four tabular benchmarks: TabArena, BeyondArena, TALENT and ScoringBench.
