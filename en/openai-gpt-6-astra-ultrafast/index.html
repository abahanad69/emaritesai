OpenAI launches Ultrafast mode for GPT-6 Astra at a steep premium

The new speed tier runs on NVIDIA Blackwell GPUs and targets coding agents.

2026-10-02 · EmaritesAI

OpenAI has switched on Ultrafast, a premium speed tier for its flagship GPT-6 Astra model. It is available to all developers through the API and, inside Codex and ChatGPT Work, to Enterprise customers and subscribers of a new Pro 500 plan that OpenAI says carries its highest usage limits.

Speed is the selling point. NVIDIA, whose Blackwell GPUs serve the tier, says Ultrafast produces tokens up to 8x faster than Astra's standard mode. OpenAI's developer account puts the API gain at up to 6x, so results will depend on where it is used. The pitch is aimed at coding agents, which repeat a write-test-fix loop many times; shaving seconds from each step adds up.

That speed is expensive. OpenAI's pricing page lists Ultrafast Astra at $60 per million input tokens and $300 per million output tokens, against $5 and $25 for the standard mode on the same page. OpenAI's own guidance tells developers to use it only when the speed justifies the cost.

According to NVIDIA, OpenAI used its own models to tune the inference software running on the GPUs, and an OpenAI inference lead credited Astra with writing high-performance kernels for NVIDIA hardware.

OpenAI says Ultrafast for its cheaper GPT-6.1 Sol model is coming soon. The launch follows a busy week in which the company also shelved a planned Astra successor over safety concerns.

3 things to know
  1. Ultrafast is a premium speed tier for GPT-6 Astra in the API, Codex and ChatGPT Work
  2. NVIDIA cites up to 8x faster output; OpenAI says up to 6x in the API
  3. Priced at $60 in / $300 out per 1M tokens on OpenAI's pricing page
