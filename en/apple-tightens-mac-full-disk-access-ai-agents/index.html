Apple tightens Mac 'Full Disk Access' as AI agents raise risks

Apps will need very explicit user action before they can see everything on a Mac.

2026-10-03 · EmaritesAI

Apple is changing how Mac apps obtain Full Disk Access, the macOS permission that lets software read almost everything on a computer. In a developer update published on October 2, the company said it will add controls so that users who really want to grant this level of access can do so only through very explicit action.

Apple explained that the setting largely bypasses normal privacy protections so that backup apps can work. It said some developers now use it in ways that expose files, mail, messages and browsing history without users fully understanding it, and warned that the danger will "grow substantially" as AI agents become more autonomous.

The announcement follows a dispute over Meta's Muse agent. An Inc. columnist reported that Muse referred to a private Messages thread he said he had never shared. Meta responded that reading Messages requires users to enable both Full Disk Access and a Messages connector. Security researcher Patrick Wardle argued that any app holding the permission can read most user files.

Desktop AI tools are under wider scrutiny. Wired reported this week on a now-patched flaw in ChatGPT's Mac app that, with malware already on a machine, could have exposed chat logs; OpenAI acknowledged the fix in its change log.

Apple has not said when the new controls will arrive or how they will look.

3 things to know
  1. Apple will require very explicit user action to grant Full Disk Access
  2. Apple says AI agents make this broad access far riskier
  3. Follows a dispute over Meta's Muse reading a journalist's messages
