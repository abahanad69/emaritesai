Surface Laptop Ultra brings Nvidia's RTX Spark to Windows at $2,599

Microsoft and Nvidia pitched local AI agents on Windows PCs with up to 128GB of unified memory and one petaflop of AI compute.

2026-10-08 · EmaritesAI

Microsoft and Nvidia used an event in San Francisco on Wednesday to show Windows PCs built to run AI agents locally. The centrepiece is the Surface Laptop Ultra, a Microsoft laptop built on Nvidia's Arm-based RTX Spark chip. It starts at $2,599, a second base model starts at about $3,700, and fully loaded versions reach about $5,900. Microsoft says the top configuration is already out of stock.

Nvidia says RTX Spark pairs a Blackwell RTX GPU with up to 6,144 cores and a Grace CPU with up to 20 cores. It offers up to 128GB of unified memory and one petaflop of FP4 AI performance. Laptop preorders opened on Wednesday and sales begin on 16 October; compact desktops follow in November. Acer, ASUS, Dell, HP, Lenovo, MSI and Gigabyte are also making RTX Spark machines, and Dell's XPS 16 Creator Edition costs $3,800.

Microsoft also announced a Surface RTX Spark Dev Box for developers at $5,999, shipping in November, according to The Verge.

On the software side, Windows 11 gets Microsoft Execution Containers, which let agents run in the background inside a sandbox under the operating system's control. Microsoft says all Windows 11 users will get it. "We needed to make the desktop the most secure place for agents to execute," Satya Nadella said.

  2. RTX Spark offers up to 128GB unified memory and 1 petaflop FP4
  3. Windows 11 adds Execution Containers to sandbox AI agents
