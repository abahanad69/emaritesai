Microsoft's Decision-1 scores AI choices for $0.042 per 1M tokens

The model returns a probability for each fixed option, built for routing, grading and agent control.

2026-10-11 · EmaritesAI

Microsoft has released Microsoft-Decision-1, a model built for one narrow job: choosing among a fixed set of answers. Instead of writing free text, it returns a calibrated probability score for each option through a structured API call. It handles yes or no questions, multiple choice and rating scales, and can grade work against a rubric.

According to Microsoft's announcement, dated October 9, the model is post-trained from Alibaba's Qwen3.5-9B for single-pass scoring, and the company plans to rebase it on other models, including its own MAI models and OpenAI's. Input costs $0.042 per million tokens and output tokens are free. It is available in Microsoft Foundry and on OpenRouter.

Microsoft says Decision-1 had the highest accuracy in its own comparison of 36 benchmarks with nearly 150,000 questions kept out of training. It reports median latency about 35 times faster than GPT-6 Sol and 2.5 times faster than the runner-up, H2O-Lightning-4B. The company also says the model changes its answer on 1.3% of input perturbations on average. These are vendor figures and have not been independently tested.

The target is the many small decisions inside agent systems: whether an agent should continue, stop, retry or hand off, which model should take a request, and how to label data or filter content. Microsoft says its Xbox research team found it competitive with GPT-6 Sol on quality while running more than 14 times faster.
