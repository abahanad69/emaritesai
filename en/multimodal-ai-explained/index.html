What is multimodal AI, and how does one model see and hear?

Models like Qwen3-Omni and Cloudflare's new Clef-omni take text, images, audio and video in a single system.

2026-10-12 · EmaritesAI

Early chatbots read and wrote text only. A multimodal model accepts several kinds of input, often text, images, audio and video, and works on them in one system instead of passing each to a separate tool.

The usual approach is to give each input type its own encoder. An image encoder cuts a picture into small patches, an audio encoder slices sound into short frames, and each piece becomes a list of numbers in the same space the model uses for words. From then on, the model treats a patch of a photo much like a token of text, so it can answer a spoken question about a video clip.

Alibaba's Qwen3-Omni is one example. Its model card describes a Thinker that handles understanding and text, and a Talker that produces speech, and lists support for text in 119 languages and speech input in 19, including Arabic. Cloudflare built its new Clef-omni on that model, removed the speech output and trained it to return scores for options instead of sentences.

The benefit is context: a model that hears the audio and sees the frames of a video can judge it better than one that only reads a transcript. The cost is compute, because images and video turn into many tokens.

Explained simply
  1. Separate encoders: Each input type, such as images or audio, gets its own encoder that turns it into numbers.
  2. Shared space: Those numbers sit in the same space as word tokens, so the model can mix them.
  3. One reasoning step: The model answers using all inputs at once, like a spoken question about a video.
  4. Output choices: Some models reply in text or speech; others, like Clef-omni, return scores for options.
3 things to know
  1. Multimodal models take text, images, audio and video in one system
  2. Encoders turn each input into numbers the model treats like words
  3. More context from video and sound costs more compute
Sources: Qwen3-Omni-30B-A3B-Instruct model card, Cloudflare blog: Clef-omni
⚠️ Qwen3-Omni uses a Thinker-Talker design; text in 119 languages, speech input in 19 incl. Arabic
⚠️ Clef-omni is built on Qwen3-Omni with speech output removed and returns option scores
