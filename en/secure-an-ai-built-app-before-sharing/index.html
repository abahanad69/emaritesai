Built an app with AI? 5 checks before you share it

AI tools can ship a working app in an afternoon, and with it an exposed key or an open database.

2026-10-09 · EmaritesAI

This week Anthropic began offering free AI security scans to open-source projects, a sign of how fast AI now finds bugs. The same is true for attackers, so an app you built with an AI assistant deserves a security pass before you share the link.

Start with secrets. Ask the assistant to list every API key and password in the project, and make sure none sit in front-end code or in your repository. Supabase's documentation is blunt: never use a secret key in the browser.

Next, check who can read your data. If you use a hosted database such as Supabase, turn on row-level security for every table that the app exposes, then test it while logged in as a second user.

Then review what you installed. Ask the assistant why each package is needed and remove the ones it cannot justify.

Treat every form field as hostile. Ask for input validation on the server, not only in the browser.

Finally, ask a fresh AI session to review the code as a security auditor, and fix what it finds. It will not catch everything, so for apps that handle payments or personal data, get a human review too.

Step by step
  1. Hide your secrets: Make sure no API key or password sits in browser code or in your repository.
  2. Lock the database: Turn on row-level security for exposed tables and test as a second user.
  3. Trim packages: Ask why each dependency is needed and remove any the AI cannot justify.
  4. Validate input: Check every form field on the server, not only in the browser.
  5. Audit twice: Have a fresh AI session review the code, then add a human review for sensitive apps.
3 things to know
  1. Keep secret keys out of front-end code and your repository
  2. Turn on database access rules and test them as a second user
  3. Ask a fresh AI session to audit the code, then add a human review
Sources: Supabase docs: Row Level Security, Anthropic: Introducing the Anthropic Cyber Mission
⚠️ Supabase advises enabling RLS on every table in an exposed schema and never using a secret key in the browser
✅ Anthropic launched free AI security scans for open-source projects this week
