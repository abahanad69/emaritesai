Meta releases Muse Wonder, its first frontier model, at $4 per 1M

Muse Wonder reaches developers through the Meta Model API with a 1M-token context, while the larger Muse Wonder Full stays inside Muse Code plans.

2026-10-13 · EmaritesAI

Meta released two new models on October 12: Muse Wonder and Muse Wonder Full. They come from Meta Superintelligence Labs and are the company's first attempt at a frontier model, following the lighter Muse Spark and the Muse agent launched earlier this year.

Muse Wonder is available now through the Meta Model API and Muse Code. Meta lists it at $4 per million input tokens, $0.20 for cached input and $20 per million output tokens, with a context window of 1 million tokens. The API follows the OpenAI format, so existing projects only need a new base URL, and the model is also listed on OpenRouter. Muse Wonder Full has no per-token price: it is limited to Muse Code subscribers on the Power and new Maximum Usage plans.

Meta says both models score at the top of tests for personal and professional agents, memory and coding, naming Harvey's Legal Agent Benchmark, FocusBench and SWE-Marathon. TechCrunch reports that Meta's own testing puts them level with Fable 5.1 and GPT-6 Astra. These results come from Meta and have not been independently checked.

The company is pitching two features. Active Memory keeps important details from earlier conversations, and Active Focus keeps the model working on hard goals and checking in before important actions. The models were trained at Meta's Prometheus data center in Ohio. Muse Wonder will start powering the Muse agent for subscribers first, and Meta says a full safety report is coming soon.
