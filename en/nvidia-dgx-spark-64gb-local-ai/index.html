NVIDIA adds a 64GB DGX Spark for running AI agents locally

The smaller desktop AI box arrives this month through six PC makers and can pair up for bigger models.

2026-10-03 · EmaritesAI

NVIDIA is adding a cheaper-to-configure option to its DGX Spark line: a version with 64GB of unified memory, arriving this month from Acer, ASUS, Dell, Gigabyte, HP and MSI. It keeps the same GB10 Grace Blackwell chip, DGX OS and software stack as the existing 128GB model.

The pitch is private, local AI. NVIDIA says a single 64GB unit can run models of up to 100 billion parameters, including agent applications, without sending data to the cloud. That suits developers and researchers who want to test models on their own data or who work under strict privacy rules.

Users who outgrow one box can add a second. Every DGX Spark includes ConnectX-7 networking, and two units joined by a cable pool their memory to 128GB, supporting models up to 200 billion parameters. In NVIDIA's own test with a 27-billion-parameter Qwen model, two clustered units ran up to 1.7 times faster than one. A new NVIDIA Sync feature is designed to set up that cluster automatically.

Later this month, NVIDIA plans a Sync Model Launcher that downloads and starts supported models with a few clicks. The system also ships ready for tools such as Ollama, vLLM and PyTorch.

NVIDIA's post does not list a price. PCMag reports the 64GB model costs $4,999, as memory shortages continue to push hardware prices up.
