Mistral releases an open 4B model that transcribes Arabic live

Voxtral Mini 4B Realtime Arabic handles dialects, Modern Standard Arabic and speech that switches languages.

2026-10-10 · EmaritesAI

Mistral AI has released Voxtral Mini 4B Realtime Arabic, a speech-to-text model that writes Arabic as it is spoken. The weights went up on Hugging Face on October 8 under the Apache 2.0 license.

The model covers Arabic dialects as well as Modern Standard Arabic, and Mistral says it is built for messy real-world audio and for code-switching, when a speaker mixes Arabic with another language in the same sentence. That is how many people in the Gulf and North Africa talk, and it has long tripped up transcription tools. The model handles Arabic only; Mistral points users of other languages to the original Voxtral Mini 4B Realtime, from which this version was fine-tuned.

According to Mistral's model card, the model has about 4.4 billion parameters and averages an 8.82% character error rate across seven Arabic benchmarks with a 480 ms transcription delay. That is within 0.91 points of Mistral's larger Voxtral Transcribe Arabic service, which scores 7.91%. Two of the test sets, ISMA and Darija in the Wild, were built with Morocco's digital transition ministry, which announced Arabic tools developed with Mistral on September 29.

Developers can run the model with vLLM, which streams audio over a WebSocket connection, or with Hugging Face Transformers. Uses Mistral lists include live captions and voice interfaces. No hosted API price is listed for this version.
