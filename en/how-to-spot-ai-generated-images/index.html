Is that image AI-made? 5 checks before you share it

Signatures and polish prove little now; the source, the file's credentials and a reverse search tell you more.

2026-10-06 · EmaritesAI

A signature in the corner used to suggest a real artist made an image. This week Nieman Lab showed ChatGPT adding the names of real New Yorker cartoonists to cartoons they never drew, so that clue is no longer safe.

Start with the source. Find the earliest post you can and check whether it comes from the artist, a news outlet or an agency that stands behind it. A screenshot shared by a fan page tells you little.

Next, look for Content Credentials. Some cameras, editing apps and AI tools attach signed C2PA data that records how a file was made, and you can upload the image to the free Verify tool at contentcredentials.org to read it. Missing data does not mean the image is fake, because most platforms strip it.

Then look closely. Text in signs, hands, jewellery, logos and backgrounds still trip up many generators, though newer models make fewer mistakes.

Finally, run a reverse image search with Google Lens or TinEye. Earlier copies, the original artist or a fact-check often turn up in seconds. If none of this settles it, say you are unsure, or don't share it.

Step by step
  1. Trace the source: Find the earliest post and check if the artist or a news outlet stands behind it.
  2. Ignore signatures: AI tools can copy a real artist's name, so a signature proves nothing alone.
  3. Read credentials: Upload the file to contentcredentials.org/verify to see any C2PA history.
  4. Check the details: Look at text, hands, logos and backgrounds, where generators still slip.
  5. Search in reverse: Run it through Google Lens or TinEye to find earlier copies or fact-checks.
3 things to know
  1. A signature no longer proves a real artist made an image
  2. Content Credentials can show how a file was made, if they survive
  3. A reverse image search often finds the original in seconds
Sources: Content Credentials Verify (C2PA), C2PA, Google Lens, TinEye, Nieman Lab
⚠️ ChatGPT added real New Yorker cartoonists' signatures to generated cartoons
✅ C2PA Content Credentials record file provenance and can be read with the Verify tool; platforms often strip metadata
