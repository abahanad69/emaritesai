Microsoft's ThinkingBox finds AI agents often fail when run 20 times

The new benchmark checks the database after each task instead of trusting what the agent says it did.

2026-10-04 · EmaritesAI

Microsoft has released ThinkingBox, an evaluation framework for AI agents published with Hugging Face on October 3. Most agent tests look at the tool calls a model makes or the answer it writes. ThinkingBox checks the database after the agent finishes, so a task only counts if the records actually changed the right way.

The team ran 18 models on 507 business workflow tasks and repeated each task 20 times. Claude Opus 5.5 led with 67.16% on the first attempt, but it completed just 47.53% of tasks correctly in all 20 runs. Kimi-K3 solved 93.89% of tasks at least once, yet only 13.41% every time.

The researchers say 79.9% of failures came from how agents handled tools, not from faulty reasoning. Among runs where the agent appeared to succeed but did not, 77.61% wrote wrong values into fields and 43.30% caused side effects nobody asked for.

The gap between one good run and a dependable result matters for companies putting agents in charge of orders, records or payments. The authors also estimate a cost per dependable task of between $6.80 and $20.68, depending on the model.

The code is MIT-licensed and the benchmark data is available on Hugging Face under the CDLA-Permissive-2.0 license, so other teams can test their own agents.

3 things to know
  1. ThinkingBox grades 507 tasks by checking the database, not the agent's report.
  2. Claude Opus 5.5 led at 67.16% first try, but 47.53% across all 20 runs.
  3. 79.9% of failures came from tool handling, not reasoning.
