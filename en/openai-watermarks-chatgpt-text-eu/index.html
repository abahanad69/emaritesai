OpenAI starts watermarking ChatGPT and Codex text in the EU

An invisible pattern in word choices will mark AI-written text for EU users, with API customers worldwide able to opt in.

2026-10-06 · EmaritesAI

OpenAI said on Monday that it will begin adding an invisible watermark to text produced by ChatGPT and Codex for users in the European Union. The rollout covers eligible users on all plans and will happen over the coming weeks. The company says it is not making the feature a global default.

The move answers the EU AI Act's transparency rules, which took effect on 2 August and require providers to mark AI-generated content in a machine-readable way. Outside the EU, developers using OpenAI's API can switch watermarking on for select models; it is off by default.

The method, called textGrain, uses a secret key to steer the model's word choices slightly. Readers see normal text, but a detector holding the key can find the statistical pattern, and it survives copy and paste. OpenAI says the mark does not identify the user and did not change model quality in its benchmarks.

Its own figures show the limits. At a 1% false-positive rate, the detector caught about 80% of 200-token passages and about 95% of 400-token passages. Replacing 10% of the words with synonyms cut detection from 92% to 66%, and replacing 25% cut it to 17%.

Because of those gaps, OpenAI is giving detector access only to approved researchers and expert organisations, case by case. It also warns that a missing watermark does not prove a human wrote the text. Anthropic announced its own text watermarking in August.

3 things to know
  1. EU users on all ChatGPT and Codex plans get watermarked text in coming weeks
  2. API customers worldwide can opt in for select models; it is off by default
  3. Swapping 10% of words cut detection from 92% to 66% in OpenAI's tests
