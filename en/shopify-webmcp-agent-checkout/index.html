Shopify lets browser AI agents complete checkout for shoppers

New WebMCP checkout tools let agents place orders, including with Shop Pay, once the buyer authorises.

2026-09-29 · EmaritesAI

Shopify has opened checkout to AI agents that operate inside a shopper's browser, TechCrunch reports, moving in the opposite direction to retailers such as Amazon that block agents from buying on users' behalf.

The company already supported WebMCP, a proposed standard for browser-based agents, on storefronts and carts, so agents could search inventory and add items. It now extends that to checkout, including Shop Pay. Three new tools, get_checkout, update_checkout and complete_checkout, let an agent inspect a checkout, change details like the delivery address or option, and place the order after the buyer authorises it, without scraping pages or reading screenshots.

The feature is rolling out to all eligible Shopify merchants, according to Gil Greenberg, a staff product manager for agentic commerce at Shopify.

Shopify also runs a hosted MCP server for agents working server-to-server. Both routes use its Universal Commerce Protocol for product search, carts and checkout.

Popular consumer agents including Meta's Muse and Instinct already have direct Shopify partnerships for agent shopping; the Instinct deal was announced the same day.

3 things to know
  1. Browser agents can now complete Shopify checkouts, incl. Shop Pay
  2. New tools: get_checkout, update_checkout, complete_checkout
  3. Orders only go through after the buyer authorises
Sources: TechCrunch
