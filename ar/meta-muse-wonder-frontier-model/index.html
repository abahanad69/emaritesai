Meta تطلق Muse Wonder أول نموذج متقدم لها

يصل Muse Wonder إلى المطورين عبر Meta Model API بنافذة سياق تبلغ مليون رمز، بينما يبقى Muse Wonder Full الأكبر ضمن اشتراكات Muse Code.

2026-10-13 · EmaritesAI

أطلقت Meta في 12 أكتوبر نموذجين جديدين هما Muse Wonder وMuse Wonder Full. يأتي النموذجان من مختبر Meta Superintelligence Labs، ويمثلان أول محاولة للشركة لتقديم نموذج ينافس في الصف الأول، بعد نموذج Muse Spark الأخف ووكيل Muse اللذين صدرا في وقت سابق من هذا العام.

أصبح Muse Wonder متاحا الآن عبر Meta Model API وخدمة Muse Code. وتحدد Meta سعره بأربعة دولارات لكل مليون رمز إدخال، و0.20 دولار للإدخال المخزن مؤقتا، و20 دولارا لكل مليون رمز إخراج، مع نافذة سياق تصل إلى مليون رمز. وتتبع الواجهة البرمجية صيغة OpenAI، فلا تحتاج المشاريع الحالية إلا إلى تغيير عنوان الاتصال، كما يظهر النموذج على منصة OpenRouter. أما Muse Wonder Full فليس له سعر لكل رمز، إذ يقتصر على مشتركي Muse Code في خطتي Power وMaximum Usage الجديدة.

تقول Meta إن النموذجين يحققان أعلى النتائج في اختبارات الوكلاء الشخصيين والمهنيين والذاكرة والبرمجة، وتذكر منها اختبار Harvey للوكلاء القانونيين وFocusBench وSWE-Marathon. وبحسب TechCrunch، تضعهما اختبارات Meta الداخلية في مستوى Fable 5.1 وGPT-6 Astra. هذه النتائج صادرة عن الشركة ولم تخضع لتحقق مستقل.

وتروج الشركة لميزتين: الأولى Active Memory التي تحتفظ بالتفاصيل المهمة من المحادثات السابقة، والثانية Active Focus التي تبقي النموذج مركزا على الأهداف الصعبة وتجعله يستأذن قبل الخطوات المهمة. ودُرب النموذجان في مركز بيانات Prometheus التابع لـMeta في ولاية أوهايو. وسيبدأ Muse Wonder بتشغيل وكيل Muse للمشتركين أولا، وتقول Meta إن تقريرا كاملا عن السلامة سيصدر قريبا.
